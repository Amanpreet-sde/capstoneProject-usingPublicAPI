# capstoneProject-usingPublicAPI
In this project,I built a website using the Express/Node.js platform, with the Axios HTTP client, that integrates a  public API . This website  interact with the public API, retrieve data, and present it in a user-friendly manner.
 ### Prerequisites  

1.Make sure you have Node.js and npm  installed on your machine.
2.Clone the repository.
3.Install dependencies: npm install  
4.Start the server: nodemon index.ejs
5.Access the application: Open your web browser and go to http://localhost:3000 to view the application.
